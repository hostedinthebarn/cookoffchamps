# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub: open the
repository's **Security** tab and choose **Report a vulnerability**.
Don't open a public issue or pull request for a vulnerability.

This is a small family project run by one person, so there's no
guaranteed response time. Reports are read and acknowledged as soon as
practical.

## Scope

The web app and API at cookoffchamps.com (the Cloudflare Worker, its
static frontend and its handling of events, photos and votes) and the
code in this repository.

Out of scope: Cloudflare's own services, and reports that only
show scripted voting getting past Turnstile without a further flaw.
